# 开口积累 · 英语短句

面向有基础但开不了口的成年学习者，独立于日语版和中越版。

## 使用

默认显示中文与表达意图，尝试开口后展开英文答案、句型说明和词汇。可切换英文提示。使用设备英语音色（包括设备可用的英式、美式音色），支持调速、跟读录音、回放和下载，不做自动评分。

支持编辑、删除撤销、批量选择、词汇掌握、场景与句型分类、分组折叠及排序。每张卡最多保留 4 条已保存录音，使用 Safari 兼容的二进制存储；保存失败保留页面会话内临时回放和下载。

录音需要 HTTPS 或 localhost。卡片存储键为 `enZhCards.v1`，录音数据库为 `enZhRecordings`，不会覆盖其他版本。

## 批量格式

卡片间空一行，词汇间使用英文分号。单条词汇格式：英文 | 音标 | 中文。

```text
英文: I could have asked for help.
中文: 我本来可以求助。
句型: could have done…
意图: 本来可以……却没有
说明: 回顾过去未采取的选择。
场景: 学习与行动
单词: ask for help | | 寻求帮助
```

JSON 文件在设置中导入。格式标识为 `en-zh-cards`，版本 1；卡片字段：`id`, `en`, `zh`, `ipa`, `pattern`, `intent`, `notes`, `scenes`, `vocab`。其中词汇字段为 `en`, `ipa`, `zh`。同 ID 覆盖，其他合并；拒绝其他版本应用的备份。

数据只在各自浏览器保存。教材通过内置内容或 JSON 分发，不自动同步。JSON 不包含录音，重要录音请下载。刷新页面会丢失未保存的临时录音。

运行检查：`node en-zh/test.cjs`。正式手机上仍需验证英语音色、录音权限、停止保存、回放及刷新后持久化。
