添加 / 编辑短句

英文和中文为必填。音标、表达意图、句型说明及词汇均可选。

批量导入短句

卡片之间空一行；词汇之间用英文分号 ; 分隔（不能用中文分号 ；）。备份 JSON 文件请在“设置”中导入。

卡片和录音只保存在当前设备的浏览器中，不会自动跨设备同步。可以用 JSON 文件分享教材与备份卡片；JSON 不包含录音，重要录音请单独下载。此版本与日语版、中越版分别存储。

朗读与备份

使用设备提供的英语音色，无需 API 密钥。美式、英式等可用音色取决于设备和浏览器；部分在线音色需要网络。

备份与分享

导出自建卡片与词汇掌握进度，不包含录音。仅支持本英语版格式；相同 ID 的卡片会被导入内容覆盖。
